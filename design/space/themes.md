# SPACE — Default Themes
Last updated: 2026-04-24

---

## Overview

Themes are the visual system applied to a user's SPACE. Each theme controls the full visual system: color palette, typography, border radius, spacing density, shadow style, and component shapes. Themes are selected in Step 4 of the SPACE setup wizard and can be changed at any time from BUILDSPACE. Individual blocks and modules can override theme defaults.

9 themes ship by default. Additional themes are available from the marketplace.

---

## Theme system — what each theme controls

| Property | Description |
|----------|-------------|
| **Color palette** | Background, surface, text primary, text secondary, accent, border, interactive states |
| **Typography** | Heading font family + weight, body font family + weight, scale ratios |
| **Border radius** | Applied to cards, buttons, inputs, images — from sharp (0px) to pill |
| **Spacing density** | Padding and margin scale — compact / comfortable / airy |
| **Shadow style** | None / subtle / soft / dramatic |
| **Component shapes** | Button shape, card style, input style — derived from radius + shadow combination |
