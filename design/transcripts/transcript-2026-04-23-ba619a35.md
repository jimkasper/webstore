**Assistant:** Captured. Two powerful additions that complete the platform economy:

**Advertising platform:**

*For users hosting sites:*
- Opt-in ad network — users allow ads on their hosted sites and profile pages
- Revenue share paid in platform credits or privacy coin
- Users control ad categories they're willing to display
- Ad visibility governed by tier system — Tier 1 users can opt out entirely

*For advertisers:*
- Self-serve dashboard to create and manage campaigns
- Targeting based on consented, tiered user data — lower tier users' data informs targeting, higher tier users are invisible unless they opt in
- Advertisers never access raw user data — targeting happens within the platform's privacy boundary
- Campaign performance metrics without exposing individual user identities

*Content creator marketplace:*
- Advertisers browse and connect directly with creators
- Creator profiles show relevant metrics — audience size, engagement, niche tags, content categories
- Creators set their rates, terms, and content boundaries
- Sponsorship agreements flow through the agreement app — full negotiation, terms, consequences, and tracking already built
- Payments in platform credits or privacy coin with automatic financial function logging

---

**Data marketplace:**

*How it works:*
- Users explicitly choose which datasets to list for sale
- The valuation engine prices each dataset based on richness, volume, and rarity
- Buyers — researchers, brands, advertisers — browse available datasets by category
- User sets the price, duration of access, and permitted use cases
- Sale is consensual, revocable, and fully logged in the audit trail

*What users can sell:*
- Raw data exports (specific categories they choose)
- Aggregated insights derived from their data
- Access to run specific algorithms against their data without exposing the underlying data — powered by zk-STARKs
- Historical records (journal patterns, mood data, financial habits, diet data)

*Privacy protections on data sales:*
- User explicitly unlocks only what they choose — zero-knowledge architecture otherwise remains intact
- Buyer access is time-limited and purpose-limited
- User can revoke access at any time — revocation is immediate and enforced
- All sales logged transparently in the user's data hub
- Tier rules still apply — a Tier 1 user selling data is a deliberate, informed choice, not a default

*Revenue:*
- Paid in privacy coin or credits directly to the seller
- Platform takes a marketplace fee
- Feeds automatically into the financial function

```
              │

              │
              └──→ Payment in privacy coin (logged in financial function)
```
